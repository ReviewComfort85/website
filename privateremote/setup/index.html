InstallИнсталиране

Download the file for each computer from your Gumroad library and install PrivateRemote on every computer you want to use, both the one you control and the one you control it from.

Свали файла за всеки компютър от библиотеката си в Gumroad и инсталирай PrivateRemote на всеки компютър, който ще ползваш: и този, който управляваш, и този, от който го управляваш.

  • Windows: run PrivateRemote-windows-x64.exe and choose Install. It installs as a service, so it works even before you log in. Allow it when Windows Firewall asks.
  • macOS: open PrivateRemote-mac-arm64.dmg and drag PrivateRemote to Applications. Then see step 9.
  • Linux: sudo apt install ./PrivateRemote-1.0.0-linux-x64.deb, or unpack the portable .tar.gz and run PrivateRemote.sh.
  • Windows: пусни PrivateRemote-windows-x64.exe и избери Install. Инсталира се като услуга, така че работи още преди да влезеш в Windows. Разреши го, когато защитната стена попита.
  • macOS: отвори PrivateRemote-mac-arm64.dmg и плъзни PrivateRemote в Applications. После виж стъпка 9.
  • Linux: sudo apt install ./PrivateRemote-1.0.0-linux-x64.deb или разархивирай преносимия .tar.gz и пусни PrivateRemote.sh.

Set the permanent passwordЗадай постоянната парола

On the computer you want to control, open Settings → Security and set a password. This is the only thing that protects the computer once the port is open, so make it long: at least 12 characters, not used anywhere else.

На компютъра, който ще управляваш, отвори Настройки → Сигурност (Settings → Security) и задай парола. Само тя пази компютъра, щом портът е отворен, затова я направи дълга: поне 12 знака, които не ползваш никъде другаде.

The password stays the same until you change it. On the other computer you can tick “Remember password” so you don't type it every time.

Паролата остава същата, докато не я смениш. На другия компютър можеш да отметнеш „Запомни паролата“ (Remember password), за да не я пишеш всеки път.

Find the computer's LAN IPНамери вътрешното (LAN) IP

PrivateRemote shows it on the main screen as “At home”, for example 192.168.1.50. Write it down: you need it for the next two steps.

PrivateRemote го показва на главния екран като „Вкъщи“ (At home), например 192.168.1.50. Запиши го: трябва ти за следващите две стъпки.

You can also find it in Windows with ipconfig (IPv4 Address), on macOS in System Settings → Wi‑Fi/Network → Details, on Linux with ip addr.

Можеш да го намериш и в Windows с ipconfig (IPv4 Address), на macOS в System Settings → Wi‑Fi/Network → Details, а в Linux с ip addr.

Reserve that IP in the router (DHCP reservation)Запази това IP в рутера (DHCP резервация)

Routers hand out LAN addresses on their own and can give your computer a different one after a restart. Then the port forward points to the wrong place and the connection stops working. A reservation fixes the address for good.

Рутерът раздава вътрешните адреси сам и след рестарт може да даде друг на компютъра ти. Тогава пренасочването сочи грешно място и връзката спира. Резервацията закрепва адреса завинаги.

  1. Open the router's admin page in a browser (often 192.168.0.1 or 192.168.1.1; it's printed on the router's label).
  2. Find DHCP → Address Reservation (some routers call it Static Lease or Fixed IP).
  3. Pick your computer from the list (or enter its MAC address) and give it the IP from step 3. Save.
  1. Отвори страницата за управление на рутера в браузъра (често 192.168.0.1 или 192.168.1.1; пише го на етикета на рутера).
  2. Намери DHCP → Address Reservation (при някои рутери е Static Lease или Fixed IP).
  3. Избери компютъра си от списъка (или въведи MAC адреса му) и му дай IP-то от стъпка 3. Запази.

Forward TCP port 21118 to that computerПренасочи TCP порт 21118 към този компютър

In the router, find Port Forwarding (also called Virtual Servers or NAT Forwarding) and add a rule like this:

В рутера намери Port Forwarding (наричано още Virtual Servers или NAT Forwarding) и добави правило като това:

NameИмеPrivateRemote
ProtocolПротоколTCP
External portВъншен порт21118
Internal IPВътрешно IP192.168.1.50
Internal portВътрешен порт21118

Use your computer's LAN IP from step 3 instead of the example. Save the rule. Only one port is needed.

Сложи твоето вътрешно IP от стъпка 3 вместо примерното. Запази правилото. Трябва само един порт.

Two routers? If your internet box is a modem‑router and you have your own router behind it, the forward must be set on both, or the modem must be in bridge mode.Два рутера? Ако устройството на доставчика е модем‑рутер и зад него имаш свой рутер, пренасочването трябва да се направи и на двата, или модемът да е в режим bridge.

Find your public IPНамери публичното си IP

PrivateRemote shows it on the main screen as “From outside”, for example 203.0.113.24:21118. You can also search “what is my IP” in any browser on that network, or look at the router's status page (WAN / Internet IP).

PrivateRemote го показва на главния екран като „Отвън“ (From outside), например 203.0.113.24:21118. Можеш и да потърсиш „what is my IP“ в браузъра от тази мрежа или да видиш статус страницата на рутера (WAN / Internet IP).

It may change. Many providers give a new public IP from time to time. If that happens, check the new one in the app. If your router has Dynamic DNS (DDNS), you can get a fixed name instead, or ask your provider for a static IP.Може да се сменя. Много доставчици дават ново публично IP от време на време. Ако стане така, виж новото в приложението. Ако рутерът ти има Dynamic DNS (DDNS), можеш да вземеш постоянно име вместо това, или да поискаш статично IP от доставчика.

Check that you're not behind CGNATПровери дали не си зад CGNAT

Some providers share one public IP between many customers (CGNAT). Then no port forward can reach you from outside, and PrivateRemote can't connect over the internet. Check it in one minute:

Някои доставчици делят едно публично IP между много клиенти (CGNAT). Тогава никое пренасочване на порт не може да те достигне отвън и PrivateRemote не може да се свърже през интернет. Провери за минута:

  1. Look at the WAN / Internet IP on the router's status page.
  2. Compare it with the public IP from step 6.
  3. If they're the same, you're fine. If they're different, or the router shows an address starting with 100.64–100.127, 10. or 192.168., you're behind CGNAT.
  1. Виж WAN / Internet IP на статус страницата на рутера.
  2. Сравни го с публичното IP от стъпка 6.
  3. Ако са еднакви, всичко е наред. Ако са различни или рутерът показва адрес, започващ със 100.64–100.127, 10. или 192.168., ти си зад CGNAT.
Behind CGNAT? Ask your provider for a public IP address. Many give one for free or for a small fee. Without it, PrivateRemote still works inside your home network.Зад CGNAT си? Поискай от доставчика си публичен IP адрес. Много го дават безплатно или срещу малка такса. Без него PrivateRemote пак работи в домашната мрежа.

ConnectСвържи се

On the computer you're sitting at, type the address into the connect box and enter the password from step 2.

На компютъра, на който седиш, напиши адреса в полето за свързване и въведи паролата от стъпка 2.

From outside (office, phone hotspot)Отвън (офис, мобилен интернет)203.0.113.24:21118
At home, same networkВкъщи, в същата мрежа192.168.1.50

At home always use the LAN IP: many routers can't loop back to their own public IP from inside.

Вкъщи винаги ползвай вътрешното IP: много рутери не могат да се свържат към собственото си публично IP отвътре.

Test it properly: to check the outside address, turn off Wi‑Fi on your laptop and connect through your phone's hotspot.Тествай правилно: за да провериш външния адрес, изключи Wi‑Fi на лаптопа и се свържи през мобилна точка за достъп от телефона.

macOS permissionsРазрешения на macOS

To be controlled, a Mac needs two permissions. Open System Settings → Privacy & Security and turn PrivateRemote on in:

За да бъде управляван, Mac има нужда от две разрешения. Отвори System Settings → Privacy & Security и включи PrivateRemote в:

  • Screen Recording (Screen & System Audio Recording on newer macOS), so the other side can see the screen.
  • Accessibility, so the other side can move the mouse and type.
  • Screen Recording (Screen & System Audio Recording в по-новите macOS), за да вижда другата страна екрана.
  • Accessibility, за да може другата страна да движи мишката и да пише.

Quit and reopen PrivateRemote after you switch them on. If you only use the Mac to control other computers, you don't need these.

Затвори и отвори PrivateRemote отново, след като ги включиш. Ако ползваш Mac-а само за да управляваш други компютри, не ти трябват.

Problems & fixesПроблеми и решения

Connects at home, not from outsideCheck the port forward (TCP 21118 → the right LAN IP), check for CGNAT (step 7), and make sure you use the public IP with :21118.
Worked yesterday, not todayThe LAN IP or the public IP changed. Compare both with what the app shows now. Set the DHCP reservation (step 4).
“Wrong password”The password is case‑sensitive. If you ticked “Remember password”, clear it and type it again.
Black screen from a MacScreen Recording is off. Turn it on (step 9) and restart the app.
I see the Mac but can't clickAccessibility is off. Turn it on (step 9) and restart the app.
Windows: nothing connectsWindows Firewall may block it. Allow PrivateRemote under Windows Security → Firewall → Allow an app.
Linux: can't be controlledLog in with an Xorg (X11) session instead of Wayland, then try again.
Very slow or choppyUsually the upload speed at home. Lower the image quality in the session toolbar.
Свързва се вкъщи, но не и отвънПровери пренасочването (TCP 21118 → правилното вътрешно IP), провери за CGNAT (стъпка 7) и дали ползваш публичното IP с :21118.
Вчера работеше, днес неСменило се е вътрешното или публичното IP. Сравни двете с това, което показва приложението сега. Направи DHCP резервацията (стъпка 4).
